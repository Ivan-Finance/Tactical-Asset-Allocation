# Tactical Asset Allocation: Building and Comparing Portfolio Strategies

Python code for backtesting simple tactical asset allocation strategies on a diversified five-asset-class ETF portfolio. It started as the empirical part of my Master's thesis in Corporate Finance and Financial Markets (University of Turin, Department of Management "Valter Cantino"), *"Tactical asset allocation: Costruzione e confronto di strategie di portafoglio"*, and has been adapted here as a standalone, reproducible project.

**Author:** Ivan Garofalo<br>

<br>

## Important: results differ from the thesis

This repository is **not** an exact replica of the thesis. It was modified to be easier to run and to be more realistic, so numbers and some conclusions are different:

| | Thesis | This repository |
|---|---|---|
| **Data source** | Static CSV files, downloaded manually | Downloaded automatically from Yahoo Finance (`yfinance`) |
| **Period** | January 2012 - January 2026 | From January 2012 to the latest available data (configurable) |
| **Commodities** | WisdomTree Broad Commodities EUR Daily Hedged ETC (00XK) | UBS Bloomberg Commodity Index SF UCITS ETF hEUR acc (same index family, available on Yahoo Finance) |
| **Prices** | Raw closing prices | Adjusted for distributions (`AUTO_ADJUST = True`) |
| **Signal timing** | Signal at the end of month *t* applied to the return of month *t* | Configurable lag (`SIGNAL_LAG`); a one-month lag is the realistic setup |

In particular, the thesis applied each month's signal to the **same month's** return, which gives the tactical strategies information they would not have in practice (look-ahead bias). The script lets you switch this off (see [Signal timing](#signal-timing-look-ahead-bias)), and doing so changes the conclusions noticeably.

## Portfolio

| Asset class | Instrument | Yahoo Finance ticker | Base weight |
|---|---|---|---|
| Global equity | iShares MSCI World UCITS ETF (Acc) | `IWDA.AS` | 40% |
| Government bonds | iShares Euro Govt Bond 3-5yr UCITS ETF | `IBCN.DE` | 30% |
| Corporate bonds | VanEck iBoxx EUR Corporate Bond UCITS ETF | `TCBT.AS` | 10% |
| Gold | Xtrackers Physical Gold EUR Hedged ETC | `XAD5.DE` | 10% |
| Commodities | UBS Bloomberg Commodity Index SF UCITS ETF hEUR acc | `DCEUAS.SW` | 10% |

## Strategies

| Strategy | Rule |
|---|---|
| **Buy & Hold** | No rebalancing: weights drift with the market. |
| **Passive** | Monthly rebalancing back to the base weights. |
| **Protective** | If the equity price is below its 12-month moving average, equity falls to 20% and government bonds rise to 50%; otherwise base weights. |
| **Aggressive** | If the equity price is above its 12-month moving average, equity rises to 60%; otherwise base weights. |
| **Gold Hedge** | If the 3-month equity return is below -5%, equity falls to 10%, government bonds rise to 40% and gold to 30%; otherwise base weights. |

Signals are evaluated at each month-end. Transaction costs are 0.1% of the turnover generated by each rebalancing.

<br>

## What the code computes

- **Performance metrics:** annualized return, volatility, Sharpe, Sortino and Calmar ratios, maximum drawdown, 95% VaR, skewness, kurtosis
- **Market regimes:** Bull, Bear and Shock, defined from the rolling 12-month return and the drawdown of the equity component
- **Robustness checks:** sub-period analysis (2012-2018 vs. 2019-2026) and transaction-cost sensitivity (0% to 20%)
- **Charts:** saved in `figures/` when `SAVE_FIGURES = True`

<br>

## Configuration

The main parameters are at the top of `tactical_asset_allocation.py`:

| Parameter | Meaning |
|---|---|
| `START_DATE` | First date of the price download |
| `END_DATE` | End of the sample (exclusive). `None` downloads up to the latest available data |
| `AUTO_ADJUST` | `True` uses prices adjusted for distributions (total-return style); `False` uses raw closing prices |
| `SIGNAL_LAG` | Months by which signals are delayed before being applied (see below) |
| `TC` | Transaction cost on turnover (default 0.1%) |
| `RISK_FREE` | Annual risk-free rate used in the ratios (default 1%) |
| `INITIAL_VALUE` | Starting capital for the cumulative-growth charts |

<br>

### Signal timing (look-ahead bias)

- `SIGNAL_LAG = 0` reproduces the thesis setup: the signal computed at the end of month *t* determines the weights applied to the return of month *t*. This is **not tradable**, because the signal already contains the return it is meant to predict.
- `SIGNAL_LAG = 1` uses the signal known at the end of month *t-1* for the weights of month *t*. This is the realistic setup and the one I recommend.

<br>

## Findings

Results depend on the sample window, the instruments and the signal timing, so I do not report fixed figures here: run the script to get the current numbers. In summary:

- **Setup of the thesis (no lag, data to January 2026):** the tactical strategies improved the risk-return profile versus the static benchmarks. Gold Hedge had the highest Sharpe ratio and the smallest drawdown, and Aggressive the highest return.
- **With a one-month signal lag:** the advantage shrinks a lot. In my test on the thesis sample, Gold Hedge's Sharpe ratio dropped to about the level of the Passive strategy, and the Protective strategy lost most of its edge. Aggressive kept a modest advantage. Part of the original result was therefore due to the signals using same-month information.
- **Takeaway:** simple, rule-based tactical overlays can change the risk profile of a portfolio, but with realistic timing, monthly data and transaction costs, the improvement is much more modest than in the original backtest, and it is not stable across samples and instruments. They are best read as risk-management rules, not as a reliable way to beat the market.

<br>

## Limitations

- Single historical sample, mostly favorable to global equities and gold.
- Only five asset classes and two simple signals (moving average, short-term drawdown); no macro variables.
- Monthly frequency and a flat proportional transaction cost; no taxes or bid-ask spreads.
- With `END_DATE = None`, the most recent month may be incomplete when the script is run mid-month.
- Yahoo Finance data can be revised or change availability over time, so results may differ slightly between runs.
- The instruments are different listings and share classes from the ones in the thesis, so small differences from the thesis figures are expected even with the same settings.
